About this template

One page below the front page, so Back, the bar and To top have something to do.

The design

Every page is plain HTML in src/. The header, footer and bars are copied from page to page, so a change to one is a change to all of them; the build does not template them. The stylesheet and the two scripts are shared files under src/assets/.

Read the README for how the pipeline works: pull requests build and test the site, a push to stage uploads a preview, and a version tag cut from main deploys production and rolls back when its checks fail.
